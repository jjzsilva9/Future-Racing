# FutureRacing

A futuristic arcade racing game built in Unreal Engine 5.7, set in a neon-lit cyberpunk city with multiple game modes.

**🎮 [Watch Gameplay Demo](https://youtu.be/h16-2F_ukHA)**

## Features

- **Game Modes**: Time trial or AI opponent race
- **Advanced Vehicle Physics**: Chaos Vehicles plugin with realistic handling
- **Cyberpunk Environment**: Procedurally-generated city using CyberScape Pro
- **Garage for customising car**: Supports saving and loading and a variety of material options
- **AI System**: Spline-based pathfinding for dynamic AI opponents
